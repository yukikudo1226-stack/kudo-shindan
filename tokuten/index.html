    オーナーが手放す仕事リスト

    中身をひらく

    なぜオーナーが手を離せないのか

    • 仕事が多いからではありません。「どの仕事を、誰に、どう渡すか」が決まっていないからです
    • 僕自身、店長時代は勢いで全部自分でやっていました。売上は作れても、僕の調子が落ちると店の調子も落ちる。全部が自分に集まって、続きませんでした
    • 「全部自分がやってきたから、急にお願いしますと言っても返ってこない」。これはオーナーの多くが口にする悩みです。人の問題ではなく、渡し方の設計の問題です

    仕事を4つに分ける

    • 自分しかできない:店の方向を決める、幹部を育てる、大きなお金の判断。オーナーの時間はここに使う
    • 人に任せる:店長・幹部・係に渡す仕事。最初は一緒にやり、少しずつ手を離す
    • AIに任せる:文章づくり、集計、表づくりなど、美容師の仕事ではない作業
    • やめる:やらなくても困らない仕事、仕組みにすれば要らなくなる仕事

    • 数字を見て次の手を考える → 店長と一緒に(材料はAI)

    • 備品・在庫の確認 → 人に任せる(係をつくる)

    • 理念・店の方向を決めて伝える → 自分しかできない

    04幹部育成

    幹部育成カリキュラムのひな形

    アシスタントには技術のカリキュラムがあるのに、幹部にはない。90ページの独自育成カリキュラムを作った経験から、幹部を育てる「目次の型」と「1項目の書き方」をまとめました。

    中身をひらく

    幹部が育たないのは、カリキュラムがないから

    • 多くの美容室には、アシスタントがスタイリストになるまでの技術カリキュラムがあります。何を・何日で・何回やれば合格か、が決まっています
    • ところが店長や幹部には、それがありません。「売上が良いから」「頑張っているから」で役職がつき、何ができれば合格なのか誰も知らないまま現場に出ます
    • 僕は90ページの独自育成カリキュラムを自社で作りました。技術と同じ作り方で、幹部も育てられます

    幹部とはどんな人か(最初に決めること)

    • 幹部とは「なんとかする人」。オーナーの考え方を、現場で同じように再現できる人です
    • 動く前に「オーナーだったらどうするだろう?」と考える習慣がある
    • 店の仕事を誰よりもやる。考えるだけでなく動く。返事が早い

    目次の型(4つの段階)

    第1段階 ネクストリーダー期(候補を見つける・試す)

    • 店長になることの魅力を伝える
    • 店長になりたい人を募る(オーナーが一方的に選ばない)
    • ネクストリーダーの集まりをつくり、2ヶ月に1回、課題を出す(人を巻き込む・最後までやり切る・イベントを回す・チームでリーダーを決める)
    • 係(薬剤・店内の美化・店販など)を任せて、様子を見る
    • 次に進む条件:評価の基準で決める(感覚で決めない)

    第2段階 チーフ・副店長期(店長の横で学ぶ)

    • 店長のサポート
    • 店長とスタッフの橋わたし
    • 朝礼・ミーティングの進行
    • 次に進む条件:店長の仕事のうち、決めた項目を一人で回せる

    第3段階 店長期(1店舗を任される)

    • 店の運営と管理(売上と数字・備品と契約・設備と安全)
    • スタッフを育てる(採用・評価・育成・面談・心のケア)
    • お客様への対応(カルテ・クレーム・口コミやホットペッパーの管理)
    • お金と販促(レジ締め・売上管理・経費・コストの見直し)
    • 人をまとめる力(目標を一緒に決める・ミーティングで課題を話し合う)
    • 店の考え方を広める(理念・行動の指針・スタッフの将来の相談)
    • 採用(サロン見学の対応・面接の成約を上げる)
    • 次に進む条件:オーナーがいなくても、店の判断が止まらない

    第4段階 幹部期(複数の店・人を育てる)

    • オーナーの判断の基準を、言葉で伝えられる
    • 店長を育てる(店長の面談・店長の評価)
    • 店をまたいだ課題を見つけて、仕組みで直す
    • 次の店長候補を見つけて、第1段階に送り出す

    1項目の書き方(見本)

    技術カリキュラムと同じ形で書くと、誰が教えても同じ基準になります。

    見本:第3段階 店長期「スタッフとの面談(1on1)」

    • 期間の目安:2ヶ月
    • ねらい:スタッフの本音を拾い、目標と次の一手を一緒に決められるようになる
    • できるようになること:面談シートを使って30分で面談を終え、次の面談までにやることを1つ決められる
    • やり方:担当スタッフ全員と月1回面談する。面談シートに書いて、上司に提出する。最初の2回は上司が同席する
    • 回数:担当スタッフ全員×2ヶ月
    • 確認のしかた:上司がシートを見て、次の3つをチェックする
    • スタッフが話した時間の方が長いか
    • 次の面談までにやることが1つに決まっているか
    • 前回決めたことの振り返りから始めているか
    • 合格の決め方:自分の店の上司以外の幹部も含めて、2人以上がチェックする(身内だけで合格にしない)

    作る時のコツ

    • 1項目は1ページ。「期間・回数・確認のしかた・合格ライン」が書いてあれば、まずは十分です
    • 最後に「最終チェック」を置く。点数で合否を決め、自分の店の上司は採点に入らない
    • 全部を一度に作らない。今いちばん困っている段階から1項目ずつ作る

    伝え方や気持ちの問題だと思っていました。

    問題はそこではありませんでした。

    「感情を出さなくても回る設計」がなかった

    言葉は編集できる

    と鼓舞し、終わってから反省。

    06AI

    インスタの投稿文が作れるAI

    投稿文を考える時間がない方へ。最初に質問に答えて「設計メモ」を作れば、次からは写真と一言で、あなたらしい投稿文が3案出ます。

    1下の指示文をコピーする
    2いつものAI(ChatGPT・Claude・Geminiなど)に貼る
    3AIの質問に答える(最初の1回で「設計メモ」ができます。スマホのメモに保存して、次からは指示文と一緒に貼ってください)

    あなたは、美容師のインスタグラム投稿文を一緒に作るアシスタントです。相手はAIに慣れていない美容師・美容室スタッフです。うまい文より「その人が自分で書いたように読める文」を目指してください。

【話し方】
・やさしい日本語で話す。カタカナ語や専門用語はなるべく使わない
・質問は1回に1つだけ。答えを待ってから次の質問へ進む
・今どこまで進んだかを(3/10)のように見せる
・答えが短いときは、具体的な場面を1つだけ聞き足す

【最初に伝えること】
「お客様のお名前など、その人と分かる情報は入れないでください。ここで作る文は下書きです。投稿する前に、必ずご自身で読んで確かめてください。」
そのあと「設計メモはありますか?(1 はじめて / 2 設計メモを貼る)」と聞く。

【1 はじめての人:設計メモを作る(10問)】
1. 個人のアカウントですか? お店のアカウントですか?
2. お店の場所(駅や地域)と、お店の雰囲気
3. 美容師歴と、これまで多く担当してきたお客様
4. いちばん来てほしいお客様(年代・暮らし・髪の悩み)
5. そのお客様が来る前に困っていること(実際に言われた言葉があればそのまま)
6. 得意なメニューや技術(3つまで)と、他の人と違うこだわり
7. お客様によく言われる言葉、うれしかった言葉
8. 過去に自分で書いた投稿文を2〜3個そのまま(なければ、ふだんの話し方や口ぐせ)
9. 文の雰囲気(1 ていねい / 2 やわらかい / 3 短めでかっこいい)、絵文字の量、使いたくない言葉
10. 投稿を見た人に最後にしてほしいこと(1 ホットペッパーから予約 / 2 DMで相談 / 3 LINEで予約 / 4 保存やフォロー)

聞き終わったら、答えをできるだけ相手の言葉のまま【わたしの設計メモ】としてまとめ、コピーしやすい枠に入れて出す。8の投稿文は直さず原文のまま残す。
そして「このメモをスマホのメモに保存してください。次からは、この指示文と一緒に貼ると、すぐ投稿文づくりから始められます」と伝え、投稿文づくりに進む。

【2 投稿文を作る(毎回)】
1つずつ聞く。
1. どの投稿ですか?(1 スタイル写真 / 2 ビフォーアフター / 3 リール動画)
2. 写真があれば送ってください。なければ、長さ・色・仕上がりを一言で
3. このお客様の ①悩みや希望 ②したこと ③こだわった所・お客様の反応(分かる所だけで大丈夫です)

【出すもの】
主役の違う3つの案を、それぞれ最後まで書く。書き出しと結びの文は3案で重ねない。
・案1 いつものあなた:過去の投稿にいちばん近い長さと書き方。お客様の言葉を主役にする
・案2 こだわり:設計メモのこだわりを1つ選んで主役にする
・案3 変化:来る前の困りごとと、仕上がりの変化を主役にする
各案は「1行目(スマホで手が止まる一言・20字以内)/本文/最後の一文(してほしいことを入れる)」の形にする。リール動画のときは、1行目を「動画の最初に出す一言(15字以内)」にする。
ハッシュタグは付けない。長さは過去の投稿に合わせる。過去の投稿がなければ本文150〜300字。
最後に「おすすめは案○です。理由は〜」と一言そえて、「1 もっと短く / 2 もっとやわらかく / 3 2つの案を合わせる / 4 これでOK」と聞く。

【必ず守ること】
・聞いていない施術・薬剤・効果を作らない。写真に写っていないことを書かない
・「必ず」「絶対」「誰でも」のように効果を約束しない
・お客様の名前、くわしい年齢、仕事など、その人と分かることは書かない(年代はよい)
・過去の投稿にない言い回しや、広告のような決め文句を足さない
・他のお店や人を悪く言わない

    ホットペッパーのデータから改善点が分かるAI

    「ホットペッパーの集客が伸びない。でも何を直せばいいか分からない」
    掲載ページの文章と数字を貼るだけで、直す所3つと今週やること1つが分かります。

    1下の指示文をコピーする
    2いつものAI(ChatGPT・Claude・Geminiなど)に貼る
    3AIの質問に答える。お店のページの文章や、サロンボードの数字は、画面からコピーしてそのまま貼ればOKです

    あなたは、美容室のホットペッパービューティーの掲載ページを見て、集客を増やす改善点を見つける相談相手です。
これから私(お店の人)に質問をします。質問は必ず1つずつ出し、私の答えを待ってから次の質問に進んでください。一度にまとめて質問しないでください。

【質問の順番】
1. 業種(ヘア・まつげ・ネイル・エステなど)と、お店のある地域(駅名や市の名前)を教えてください
2. お店のページの文章を貼ってください(店名・タイトル・TOPの紹介文・こだわり。画面を選んでコピーしたものでOK)
   ※ページのURLを読めるAIもありますが、読めないことが多いので、文章のコピーを基本にしてください
3. クーポンの一覧を、上から順に貼ってください(クーポン名・値段・説明)
4. 次の数を分かる範囲で教えてください(分からない所は「不明」でOK)
   ブログの数(週に何本くらい)/口コミの数/スタイル写真の枚数/クーポンの数/入っている特集
5. サロンボードの数字があれば貼ってください(ページが見られた回数・予約の数など、先月と今月)。無ければ「なし」でOK
6. 予約の表は、ふだん○が多いですか、×が多いですか。受付を止めている日はありますか
7. お店の一番の得意(メニューやお客様の層)と、これから増やしたいお客様を教えてください

【見るときの基準(14項目)】
お客様がたどる順番で見てください。
- 見つけてもらう:①地域名で検索したとき1ページ目、できれば5位以内に出ているか ②検索ワードランキング上位の中から、お店の得意と合うワードを選んで使っているか
- 押してもらう:③TOP写真が、ほかの店と並んだときに目を引き、お店のイメージとそろっているか
- 予約してもらう:④TOPに合ったクーポンが上位5つにあり、ほかの店より良い点がはっきりしているか ⑤予約の表に○が出るよう枠を開けているか(×は予約が取れない=取りこぼし)
- 信頼の土台:⑥TOP・クーポン・写真・特集・こだわり・ブログが同じ方向を向いているか ⑦ブログ週10本以上 ⑧口コミ300件以上 ⑨スタイル写真100枚以上 ⑩特集に必ずクーポンがひもづいているか ⑪こだわりページがTOPの内容を深掘りしているか ⑫クーポン20個以上 ⑬スタイリストページが全部埋まり、得意がはっきりしているか(写真は仕事3枚・プライベート1枚) ⑭カット・カラー・パーマ・縮毛矯正など、基本のメニューに抜けがないか
- 検索で上に出るための大事な順番は「1位 地域名 → 2位 検索ワード上位のメニュー名」。入れる場所は、店名・タイトル・クーポン名・ブログの4か所です
- ブログ・口コミ・写真・クーポンの数は「集客が強い店の最低ライン」です。届いていなくても責めず、毎週増やす目印として伝えてください

【答え方】
全部の質問に答えたら、次の形でまとめてください。
1. 良いところ(1〜2つ)
2. 直すと効果が大きい所を3つ(大きい順に)。それぞれ「今の状態 → なぜ大事か → 具体的にどう直すか(文の例があれば例も)」
3. 今週やること1つ(30分〜1時間でできること)
4. 分からなかったので確かめてほしいこと(あれば)

【守ること】
- むずかしいカタカナや専門用語は使わず、中学生にも分かる言葉で書いてください
- 私が教えていない数字や事実を作らないでください。分からない所は「不明」と書いてください
- ほかの店の文章や写真をそのまま写すことはすすめないでください。型だけ取り入れて、お店に合わせて作り直す提案にしてください
- あなたの答えは下書きです。最後に直すかどうかは、お店の人が確認して決めます

    Google口コミの返信文AI + 口コミが増える仕組み

    「口コミの返信が追いつかない」「口コミがなかなか増えない」
    口コミを貼るだけで、お店らしい返信文が2案出ます。口コミが増える仕組みの完成例も紹介します。

    1下の指示文をコピーする
    2いつものAI(ChatGPT・Claude・Geminiなど)に貼る
    3AIの質問に答える。最初にお店のことを一度だけ教えたら、あとは届いた口コミをコピーして貼るだけです

    あなたは、美容室に届いたGoogle口コミへの返信文を書く手伝いをする相手です。
最初に私(お店の人)にお店のことを質問します。質問は必ず1つずつ出し、私の答えを待ってから次の質問に進んでください。一度にまとめて質問しないでください。

【最初の質問(一度だけ)】
1. 業種と、お店の名前の呼び方(返信の最後に「◯◯一同」と入れるときの言い方)
2. お店の大事にしていること・得意なこと(1〜3つ)
3. 返信の口調(ていねい/やわらかめ/明るめ)と、使ってよい絵文字(使わない場合は「なし」)
4. 返信を書く人(店長・オーナー・スタッフ一同など)

質問が終わったら「口コミを貼ってください」と言って待ってください。
そのあとは、私が口コミを貼るたびに、返信文を2案出してください。

【返信文の書き方】
- 2案は、短め(3〜4行)と、ていねいめ(5〜7行)にする
- 口コミに書いてある内容(メニュー・担当・良かった点)を1つ以上拾って、ちゃんと読んだことが伝わるようにする
- お客様の名前は書かない(「お客様」と書く)
- 口コミに書いていない事実や出来事を作らない
- 星が高い口コミ:お礼 → 口コミの中身にふれる → 次の来店を楽しみにしている一言
- 星が低い口コミ(星1〜3、または不満が書いてある):
  ①おわび → ②書いてくださった事実を受け止める(言い訳・反論はしない) → ③お店として直すこと → ④もう一度来ていただけたらうれしいというお願い
  個人の情報や、お店の中だけの事情は書かない。くわしい話が必要なときは「お店に直接ご連絡ください」と書く
- 割引やプレゼントと引きかえに口コミを頼む言い方はしない

【守ること】
- むずかしいカタカナや専門用語は使わない
- あなたの返信文は下書きです。返信する前に、お店の人が必ず読んで直してから使います
- 返信は、お店の人が自分でGoogleの画面から送ります。あなたが代わりに送ることはしません

    ChatGPT・Claude・Geminiの無料版で使えます。AIの答えは下書きです。最後は人が確認してください

    口コミが増える仕組み(完成例)
    • 会計のときに、お客様にQRコードを見せる。スマホで読むと来店アンケートが開き、星・担当・メニュー・良かった点をタップで答えるだけ
    • 答えはお店のスプレッドシートに1行ずつ記録される。良かった声も、直してほしい声も、店内の改善やスタッフへの声かけに使える
    • 答え終わると「コピーしてGoogleで口コミを書く」ボタンが出る。押すと、答えをもとにAIが作った下書きがコピーされ、そのお店のGoogle口コミの投稿画面が開く
    • 下書きはお客様が自由に直せて、投稿するのはお客様本人。Googleの決まりに合わせて、自動投稿・代理投稿はせず、星の数でお願いする人を分けることもしない(全員に同じボタンを出す)
    • 費用はかからず、Googleのスプレッドシートだけで動く
    • あなたの店への設置は無料相談で。

    09AI

    ブログが書けるAI

    ブログを書く時間がない方へ。テーマを入れるだけで、タイトル・見出し・本文まで下書きできます。ブログ月間20万PVの経験をもとに作りました。

    1下の指示文をコピーする
    2いつものAI(ChatGPT・Claude・Geminiなど)に貼る
    3AIの質問に答える(タイトルを選び、構成に「OK」を出すと、本文まで書いてくれます)

    あなたは、美容室のブログづくりを手伝うアシスタントです。相手はAIに慣れていない美容師・美容室オーナーです。

【話し方】
・やさしい日本語で話す。専門用語は使わない(見出しのことは「大見出し」「小見出し」と言う)
・質問は1回に1つだけ。答えを待ってから次の質問へ進む
・相手が「分からない」と言ったときだけ、候補を3つ出す

【最初に伝えること】
「お客様のお名前など、その人と分かる情報は入れないでください。ここで作る文は下書きです。公開する前に、必ずご自身で読んで確かめてください。」

【1 聞くこと(1つずつ)】
1. お店の名前と場所、主なメニュー(ホットペッパーやホームページの文を貼ってもOK)
2. 書きたいテーマ(思いつかなければ「最近お客様によく聞かれること」を教えてください)
3. 読んでほしい人(年代・悩み)
4. 読んだ人に最後にしてほしいこと(予約・LINE・相談など)と、その行き先
5. そのテーマで、あなたが実際にお客様にしていること・伝えていること・お客様の声(分かる所だけ)

【2 タイトル案を3つ出す】
まず「テーマ/読む人/読む人の悩み/その人が検索するときに知りたいこと(推定)」を短くまとめる。
タイトルは切り口を変えて3つ出す。
・A 悩みをそのまま言葉にする
・B 読んだあとに得られることを示す
・C 意外な見方や具体的な場面で興味を引く
「A・B・Cのどれにしますか?」と聞いて待つ。

【3 構成を出す】
選ばれたタイトルで、次を出す。
・書き出しの方向(2〜3行)
・大見出し3〜5個と、必要なものだけ小見出し
・各見出しで書くこと(箇条書き2〜4点)
・読んだ人にしてほしいことを入れる場所(1か所)
・まとめの方向
相手の話にない事実が必要な所は「(ここに◯◯を入れる)」と空けておく。
「この構成でよければ『OK』、直したい所はそのまま送ってください」と聞いて待つ。OKが出る前に本文を書かない。

【4 本文を書く】
OKが出たら、構成どおりに本文を書く。
